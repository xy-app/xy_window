# 消息通知 (NotifyMessage)

在操作系统桌面弹出原生非模态 Toast 气泡消息通知，引起用户注意或报告后台任务执行状态，完全不阻塞当前流程继续执行。

## 平台与权限

* **支持平台**: 跨平台 (`Windows` WinRT Toast / `Linux` D-Bus 通知标准 / `macOS` 原生通知中心)
* **权限要求**: 普通用户权限（无需管理员提权）

## 运行参数

* **通知标题 (`title`)**
  * 类型: `string`
  * 默认值: `"任务通知"`
  * 描述: 通知气泡的主题标题。常用预设：`提示`, `警告`, `执行完成`。
* **通知内容 (`body`)**
  * 类型: `string`
  * 默认值: `""`
  * 描述: 通知的正文详细说明文字。
* **应用名称 (`app_name`)**
  * 类型: `string`
  * 默认值: `"小友+"`
  * 描述: 来源应用程序标识名称。常用预设：`小友+`。
* **通知图标 (`icon`)**
  * 类型: `string`
  * 默认值: `""`
  * 描述: 预设图标名称或本地图片文件绝对路径。常用预设：`info`, `warning`, `error`。
* **停留时长(毫秒) (`timeout`)**
  * 类型: `number`
  * 默认值: `5000`
  * 描述: 通知显示持续毫秒数，`0` 表示常驻系统通知中心。常用预设：`3000`, `5000`, `10000`, `0`。
* **提示音 (`sound`)**
  * 类型: `string`
  * 默认值: `"default"`
  * 描述: 提示音效模式。常用预设：`default` (系统默认音效), `silent` (静音通知)。

## 输出

* 类型: `bool`
* 描述: 消息通知提交执行状态 (`true` 表示通知已成功提交至系统通知中心)。

## 使用示例

```json
{
    "tag": "NotifyMessage",
    "title": "任务通知",
    "body": "后台数据采集任务已完成",
    "app_name": "小友+",
    "icon": "info",
    "timeout": 5000,
    "sound": "default"
}
```
