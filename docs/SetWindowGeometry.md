# 设置窗口位置与尺寸 (SetWindowGeometry)

原子化同步调整窗口在屏幕上的 X, Y 物理像素坐标以及 Width, Height 尺寸，避免分步执行平移与缩放导致的界面闪烁与撕裂。

## 平台与权限

* **支持平台**: `Windows`
* **权限要求**: 普通用户权限（无需管理员提权）

## 运行参数

* **目标窗口 (`window`)**
  * 类型: `Wnd` / `string`
  * 默认值: `""`
  * 描述: 目标窗口对象、标题表达式或句柄。
* **X 坐标 (`x`)**
  * 类型: `number`
  * 默认值: `-1`
  * 描述: 目标屏幕 X 坐标 (-1 表示保持不变)。
* **Y 坐标 (`y`)**
  * 类型: `number`
  * 默认值: `-1`
  * 描述: 目标屏幕 Y 坐标 (-1 表示保持不变)。
* **宽度 (Width) (`width`)**
  * 类型: `number`
  * 默认值: `-1`
  * 描述: 目标窗口宽度 (-1 表示保持不变)。
* **高度 (Height) (`height`)**
  * 类型: `number`
  * 默认值: `-1`
  * 描述: 目标窗口高度 (-1 表示保持不变)。

## 输出

* 类型: `bool` (`Number`)
* 描述: 返回操作执行结果状态 (`1` 成功，`0` 失败)。

## 使用示例

```json
{
    "tag": "SetWindowGeometry",
    "window": "Foreground",
    "x": 100,
    "y": 100,
    "width": 1280,
    "height": 720
}
```
