# 闪烁与高亮窗口 (FlashWindow)

在屏幕上对目标窗口外框进行高对比度彩色高亮闪烁，或闪烁系统任务栏图标以引起操作员或调试人员注意。支持工业级 RPA 高亮提示（类似 UiPath Highlight 边框高亮）。

## 平台与权限
* **支持平台**: `Windows`
* **权限要求**: 普通用户权限（无需管理员提权）

## 运行参数

| 参数名 | 类型 | 默认值 | 预设选项 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `window` | `String` / `Wnd` | 空 | 变量/表达式引用 | 目标窗口对象、标题或窗口句柄 |
| `mode` | `String` | `"Highlight"` | `Highlight`, `Taskbar`, `Both` | 闪烁模式：屏幕边框高亮、任务栏图标闪烁或二者同时执行 |
| `color` | `String` | `"#FF3B30"` | `#FF3B30`, `#FF9500`, `#007AFF`, `#34C759` | 高亮边框颜色 (Hex 格式颜色代码) |
| `count` | `Number` | `3` | `1`, `3`, `5` | 闪烁或高亮脉冲次数 |
| `duration` | `Number` | `1000` | `500`, `1000`, `2000` | 高亮或闪烁的总持续时间（毫秒） |

## 输出

* 无（顺序执行下一动作）
