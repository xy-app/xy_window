# 闪烁窗口提示 (FlashWindow)

在屏幕上对目标窗口外框进行高对比度彩色高亮边框闪烁，或闪烁系统任务栏图标以引起操作员注意。提供类似 UiPath Highlight 的工业级自动化视觉指引。

## 平台与权限

* **支持平台**: `Windows`
* **权限要求**: 普通用户权限（无需管理员提权）

## 运行参数

* **目标窗口 (`window`)**
  * 类型: `Wnd` / `string`
  * 默认值: `""`
  * 描述: 目标窗口对象、标题表达式或窗口句柄。常用预设：`Foreground`。
* **闪烁模式 (`mode`)**
  * 类型: `string`
  * 默认值: `"Highlight"`
  * 描述: 提示模式。常用预设：`Highlight` (屏幕边框高亮), `Taskbar` (任务栏图标闪烁), `Both` (边框与任务栏同时执行)。
* **边框高亮颜色 (`color`)**
  * 类型: `string`
  * 默认值: `"#FF3B30"`
  * 描述: 高亮边框颜色 Hex 代码。常用预设：`#FF3B30` (红色), `#FF9500` (橙色), `#007AFF` (蓝色), `#34C759` (绿色)。
* **闪烁次数 (`count`)**
  * 类型: `number`
  * 默认值: `3`
  * 描述: 闪烁或高亮脉冲次数。常用预设：`1`, `3`, `5`。
* **持续时间 (ms) (`duration`)**
  * 类型: `number`
  * 默认值: `1000`
  * 描述: 高亮或闪烁的总持续时间（毫秒）。常用预设：`500`, `1000`, `2000`。

## 输出

* 类型: `bool`
* 描述: 闪烁高亮提示执行状态 (`true` 表示高亮脉冲执行完成)。

## 使用示例

```json
{
    "tag": "FlashWindow",
    "window": "Foreground",
    "mode": "Highlight",
    "color": "#FF3B30",
    "count": 3,
    "duration": 1000
}
```
