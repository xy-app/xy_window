# 窗口标题 (WindowCaption)

获取或修改指定窗口的标题栏文本内容。当输入标题为空时执行查询操作并返回当前标题；当输入新标题时不为空时更新窗口标题。

## 平台与权限
* **支持平台**: `Windows`
* **权限要求**: 普通用户权限

## 运行参数

| 参数名 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `window` | `String` / `Wnd` | `""` | 目标窗口对象或句柄 |
| `caption` | `String` | `""` | 新的窗口标题文本。留空时表示查询当前窗口标题 |

## 输出

* **窗口标题 (`String`) 或 修改结果 (`Number`)**: 
  * 查询模式（标题留空）：返回当前窗口的标题文本 (`String`)
  * 设置模式（标题非空）：返回设置结果 (`1` 为成功，`0` 为失败)
