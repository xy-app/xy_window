# 窗口坐标 (WindowPoint)

计算并获取指定窗口在特定相对锚点（左上角、右上角、左下角、右下角、中心点）叠加相对偏移量后的屏幕绝对物理坐标。常用于精确点击窗口内部特定区域。

## 平台与权限
* **支持平台**: `Windows`
* **权限要求**: 普通用户权限

## 运行参数

| 参数名 | 类型 | 默认值 | 预设选项 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `window` | `String` / `Wnd` | `""` | 窗口对象/句柄 | 目标窗口对象 |
| `relative` | `String` | `"TopLeft"` | `TopLeft`, `TopRight`, `BottomLeft`, `BottomRight`, `Center` | 相对基准锚点方位 |
| `offset` | `String` / `Tuple` | `"0, 0"` | `0, 0`, `10, 10` | 相对锚点的 X, Y 偏移像素量 (如 `"50, 100"`) |

## 输出

* **屏幕绝对坐标 (`Tuple` of `Real`)**: 包含 `[X, Y]` 浮点像素绝对坐标的元组
