# 窗口移动 (WindowXy)

获取或移动指定窗口在桌面屏幕上的 X, Y 物理像素坐标位置。

## 平台与权限
* **支持平台**: `Windows`
* **权限要求**: 普通用户权限

## 运行参数

| 参数名 | 类型 | 默认值 | 预设选项 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `window` | `String` / `Wnd` | `""` | 窗口对象/句柄 | 目标窗口对象 |
| `xy` | `String` / `Tuple` | `""` | `0, 0`, `100, 100`, `200, 200` | 目标坐标（X, Y），留空表示查询当前窗口左上角位置 |

## 输出

* **窗口坐标 (`Tuple` of `Real`)**: 包含 `[X, Y]` 的元组
