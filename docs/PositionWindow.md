# 窗口置顶 (PositionWindow)

更改窗口的 Z-Order 层叠顺序（例如设置窗口最顶层显示、取消置顶或置底）。

## 平台与权限
* **支持平台**: `Windows`
* **权限要求**: 普通用户权限（注：针对部分 UWP 隔离沙箱窗口，Win32 Z-Order 需遵从系统安全层叠限制）

## 运行参数

| 参数名 | 类型 | 默认值 | 预设选项 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `order` | `String` | `"-1"` | `-1`, `0`, `-2`, `1` | Z-Order 位置：`-1` (WH_TOPMOST 最顶层), `0` (WH_TOP 顶层), `-2` (WH_NOTOPMOST 取消最顶层), `1` (WH_BOTTOM 最底层) |
| `window` | `String` / `Wnd` | `""` | 窗口对象/句柄 | 要设置的目标窗口对象 |

## 输出

* **操作结果 (`Number`)**: `1` 表示成功，`0` 表示失败
