# 窗口大小 (WindowSize)

获取或调整指定窗口的宽度和高度尺寸。当尺寸参数为空时执行尺寸查询；当尺寸参数非空时执行窗口大小调整。

## 平台与权限
* **支持平台**: `Windows`
* **权限要求**: 普通用户权限

## 运行参数

| 参数名 | 类型 | 默认值 | 预设选项 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `window` | `String` / `Wnd` | `""` | 窗口对象/句柄 | 目标窗口对象 |
| `size` | `String` / `Tuple` | `""` | `800, 600`, `1024, 768`, `1280, 720`, `1920, 1080` | 目标尺寸（宽度, 高度），留空表示查询当前窗口尺寸 |

## 输出

* **窗口尺寸 (`Tuple` of `Real`)**: 包含 `[Width, Height]` 的元组
