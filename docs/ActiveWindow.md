# 激活窗口 (ActiveWindow)

将指定的窗口激活并切换至前台焦点状态（恢复最小化、置前并授予键盘输入焦点）。

## 平台与权限
* **支持平台**: `Windows`
* **权限要求**: 普通用户权限

## 运行参数

| 参数名 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `window` | `String` / `Wnd` | `""` | 要激活的目标窗口对象 (`Wnd`)、窗口标题、类名或窗口句柄 |

## 输出

* **激活窗口对象 (`Wnd`)**: 成功激活后的窗口对象（支持直接传递给后续操作使用）
