# 激活窗口 (ActiveWindow)

将指定的软件窗口置顶并激活到最前面焦点状态（恢复最小化、切换前台并授予键盘输入焦点）。

## 平台与权限

* **支持平台**: `Windows`
* **权限要求**: 普通用户权限（无需管理员提权）

## 运行参数

* **目标窗口 (`window`)**
  * 类型: `Wnd` / `string`
  * 默认值: `""`
  * 描述: 待激活的目标窗口对象 (`Wnd`)、窗口标题、类名或句柄表达式。常用预设：`Foreground`, `Desktop`。
* **超时时间 (毫秒) (`timeout_ms`)**
  * 类型: `number`
  * 默认值: `5000`
  * 描述: 查找或激活目标窗口的最长等待超时时间（毫秒，0 表示立即尝试）。

## 输出

* 类型: `Wnd`
* 描述: 成功激活的目标窗口对象 (`Wnd`)，若目标窗口不存在或激活失败返回空句柄 (`0`)。可直接传递给后续操作使用。

## 使用示例

```json
{
    "tag": "ActiveWindow",
    "window": "Foreground",
    "timeout_ms": 5000
}
```
