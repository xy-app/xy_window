# 关闭窗口 (CloseWindow)

向指定的软件窗口或弹窗发送安全关闭指令 (`WM_CLOSE`)，请求其正常退出并释放系统资源。

## 平台与权限

* **支持平台**: `Windows`
* **权限要求**: 普通用户权限（若目标窗口以管理员身份运行，需以同等权限运行本程序方可通过 UIPI 发送消息）

## 运行参数

* **目标窗口 (`window`)**
  * 类型: `Wnd` / `string`
  * 默认值: `""`
  * 描述: 待关闭的目标窗口对象 (`Wnd`)、窗口标题、类名或句柄表达式。常用预设：`Foreground`。
* **超时时间 (毫秒) (`timeout_ms`)**
  * 类型: `number`
  * 默认值: `5000`
  * 描述: 等待目标窗口响应关闭指令的最长超时时间（毫秒，0 表示立即发送）。
* **超时强制关闭进程 (`force_kill`)**
  * 类型: `boolean`
  * 默认值: `false`
  * 描述: 优雅关闭超时或目标窗口无响应时是否强制终止所属进程。

## 输出

* 类型: `bool`
* 描述: 关闭消息下发执行状态 (`true` 表示成功向目标窗口发送关闭信号)。

## 使用示例

```json
{
    "tag": "CloseWindow",
    "window": "Foreground"
}
```
