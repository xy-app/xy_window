# 窗口显示隐藏 (WindowVisible)

获取指定窗口的当前可见性状态，或显式控制将窗口显示或隐藏。常配合 `FindWindow` 检索到的隐藏窗口进行唤醒与显示。

## 平台与权限
* **支持平台**: `Windows`
* **权限要求**: 普通用户权限

## 运行参数

| 参数名 | 类型 | 默认值 | 预设选项 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `window` | `Wnd` / `MixedType` | `""` | `Desktop`, `Foreground` | 目标窗口对象（支持引用上游 `FindWindow` 或 `ActiveWindow` 生成的对象） |
| `visible` | `String` / `MixedType` | `""` | `Show (显示)`, `Hide (隐藏)`, `查询状态 (Query)` | 目标操作：`Show` / `1` (显示窗口), `Hide` / `0` (隐藏窗口), 留空 (仅查询当前可见状态) |

## 输出

* **可见性状态 (`Number`)**: `1` 表示窗口可见/显示操作成功，`0` 表示窗口隐藏
