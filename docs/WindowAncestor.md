# 祖先窗口 (WindowAncestor)

检索指定子窗口在 UI 树中的上级祖先窗口对象（包括直接父窗口、顶级父窗口以及顶级所有者窗口）。

## 平台与权限
* **支持平台**: `Windows`
* **权限要求**: 普通用户权限

## 运行参数

| 参数名 | 类型 | 默认值 | 预设选项 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `ancestor` | `String` | `"父窗口 (Parent)"` | `父窗口 (Parent)`, `顶层根窗口 (Root)`, `顶层所有者 (RootOwner)` | 检索类型：直接父级、顶级根窗口、顶级拥有者窗口 |
| `window` | `String` / `Wnd` | `""` | `Desktop`, `Foreground` | 目标子窗口对象（支持变量引用或标题/类名/句柄） |

## 输出

* **祖先窗口对象 (`Wnd`)**: 检索获取到的父窗口/根窗口对象
