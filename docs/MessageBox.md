# 弹出提示消息框 (MessageBox)

在屏幕上弹出一个系统原生模态对话框，显示自定义消息内容，并阻塞流程直到操作员点击按钮确认或关闭，返回所选按钮代码。

## 平台与权限

* **支持平台**: 跨平台 (`Windows` / `Linux` / `macOS` 全平台支持，无图形界面自动降级控制台交互)
* **权限要求**: 普通用户权限（无需管理员提权）

## 运行参数

* **弹窗标题 (`caption`)**
  * 类型: `string`
  * 默认值: `"提示"`
  * 描述: 对话框标题栏文字。常用预设：`提示`, `警告`, `确认`。
* **提示内容 (`text`)**
  * 类型: `string`
  * 默认值: `"操作完成"`
  * 描述: 对话框正文消息，支持多行文本。
* **按钮组合 (`button_type`)**
  * 类型: `string`
  * 默认值: `"OK"`
  * 描述: 按钮样式组合。常用预设：`OK` (确定), `OKCANCEL` (确定/取消), `YESNO` (是/否), `YESNOCANCEL` (是/否/取消), `RETRYCANCEL` (重试/取消)。

## 输出

* 类型: `number`
* 描述: 用户点击的按钮代码：1 (确定/OK), 2 (取消/CANCEL), 3 (中止/ABORT), 4 (重试/RETRY), 5 (忽略/IGNORE), 6 (是/YES), 7 (否/NO)。

## 使用示例

```json
{
    "tag": "MessageBox",
    "caption": "提示",
    "text": "自动化流程已执行完毕，是否继续？",
    "button_type": "YESNO"
}
```
