# 特定窗口 (SpecialWindow)

获取系统内已知的特定特殊窗口对象（如 `Desktop` 桌面顶级容器窗口、`Foreground` 当前拥有焦点的激活前台窗口）。

## 平台与权限
* **支持平台**: `Windows`
* **权限要求**: 普通用户权限

## 运行参数

| 参数名 | 类型 | 默认值 | 预设选项 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `window` | `String` | `"Desktop"` | `Desktop`, `Foreground` | 要获取的特殊窗口类型 |

## 输出

* **窗口对象 (`Wnd`)**: 获取到的桌面或焦点前台窗口对象
